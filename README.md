# Лабораторна робота № 5. Варіант 19

**Маятник під дією періодичної сили** — візуальна модель на C++17 з бібліотекою SFML 3, збирання через CMake, залежності — через vcpkg (manifest mode).

Виконала: Процик Анна Сергіївна, група ФІТ 3-8.

## Фізична модель

Математичний маятник довжиною `L` і масою `m` із тертям у підвісі та зовнішньою періодичною силою `F(t) = F0·cos(Ω·t)`, що діє на тягарець по дотичній до траєкторії:

```
θ'' = −(g/L)·sin θ − γ·θ' + F0/(m·L)·cos(Ω·t)
```

Чисельний розв'язок — метод Рунге–Кутти 4-го порядку з фіксованим кроком `dt = 0,002 с`.
Параметри за замовчуванням: g = 9,81 м/с², L = 1 м, m = 1 кг, γ = 0,5 1/с, F0 = 1 Н, Ω = 2 рад/с, θ(0) = 0,3 рад.

## Керування

| Клавіша | Дія |
|---|---|
| `Space` | пуск / пауза |
| `R` | перезапуск моделювання |
| `←` / `→` | зменшити / збільшити частоту впливу Ω (крок 0,1 рад/с) |
| `↑` / `↓` | збільшити / зменшити амплітуду сили F0 (крок 0,25 Н) |
| `Esc` | вихід |

У вікні відображаються: маятник зі стрілкою зовнішньої сили, час, кут, кутова швидкість, Ω, F0, власна частота ω₀, згасання, виміряна амплітуда (максимум |θ| за останні 10 с) і графік θ(t).

## Збирання

1. Встановити vcpkg і змінну середовища `VCPKG_ROOT`.
2. У каталозі проєкту виконати `vcpkg x-update-baseline --add-initial-baseline`.
3. Відкрити папку у Visual Studio 2022 (**File → Open → Folder**), дочекатися конфігурації CMake.
4. Вибрати ціль `SFML_Lab.exe` і запустити (Ctrl+F5).

Перше збирання довге: vcpkg компілює SFML.

## Експеримент

Залежність амплітуди усталених коливань від частоти впливу (F0 = 0,5; 1; 2 Н) наведено у звіті. Резонанс спостерігається поблизу ω₀ = √(g/L) ≈ 3,13 рад/с; зі зростанням F0 максимум зсувається вліво (нелінійність маятника).
